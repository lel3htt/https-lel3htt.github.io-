# Portfólio da Letícia

Site pessoal responsivo desenvolvido com HTML, CSS e JavaScript.

## Estrutura
- `index.html`: página inicial
- `pages/`: páginas Sobre mim e Formação e habilidades
- `css/style.css`: estilos e adaptação para celular
- `js/script.js`: menu mobile e ano automático
- `images/`: coloque sua foto como `minha-foto.jpg`

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e pastas para a raiz do repositório.
3. Acesse Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione `main` e `/ (root)` e clique em Save.
6. Aguarde o endereço do site aparecer na página do GitHub Pages.

Personalize e revise as informações antes da entrega.
